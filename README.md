## Setup Instructions
1. Install dependencies: npm install
2. Install express: npm install express
3. Install cypress: npm install cypress --save-dev

## Running the Application
1. Start the server in the main program directory: node server.js
2. Open browser: http://localhost:3000/
3. If not redirected to login screen: http://localhost:3000/login.html

## Running Cypress Tests
### Headless Mode
npx cypress run --browser chrome

### Interactive Mode, In Browser
npx cypress open --browser chrome
